## 2. How the site is built and published

- Static site generated by Python: `build.py` + `src/content.py` (all page text, PROJECTS list, CASES dict for case-study pages, FAQ). Output goes to `dist/` (live) and `preview/`.
- Other source: `assets/style.css`, `assets/main.js`, `assets/brand-mark.svgfrag` (header logo), `src/panels.json` (panel catalog), `img/` (all photos; each has a `-sm.jpg` thumbnail), `img/logo/` (logo files), `renders/` (Blender scripts for concept images), `logo/` (logo generator scripts and CNC vectors).
- Hosting: GitHub Pages serves the `main` branch. DNS is at Wix: A records 185.199.108–111.153 and CNAME www → mattjrogers-git.github.io. The `main` branch must keep the `CNAME` (hudsoncnc.com) and `.nojekyll` files (build.py copies them).
- To update: clone the `source` branch → edit → `python3 build.py` → commit and push `source` → copy `dist/` contents into a `main` checkout → commit and push `main`. Pages updates in about a minute.
- **GitHub token:** pushing needs Matt's fine-grained token (scoped to the hudsoncnc repo). It is NOT stored in any doc or memory. Ask Matt to paste it each session. In the sandbox, pass it as a Basic auth header: `git -c credential.helper= -c http.extraHeader="Authorization: Basic $(printf 'x-access-token:%s' "$TOKEN" | base64 -w0)" push https://github.com/mattjrogers-git/hudsoncnc.git HEAD:main`.
- Commit messages end with the Co-Authored-By / Claude-Session lines from the session's system reminder.
- After changing site code, also update the project copies (site-source/content.py, build.py, style.css) with project_write.
